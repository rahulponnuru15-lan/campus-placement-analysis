# Campus Placement Analysis

This project analyzes the Kaggle dataset "Factors Affecting Campus Placement" by Ben Roshan (Jain University).  
The aim is to determine which academic and employability factors influence student placement outcomes.

---

## Objectives
1. Identify the factors influencing whether a student gets placed.
2. Check if academic percentage significantly affects placement.
3. Determine which degree specialization is most in demand by companies.
4. Analyze salary distribution among placed students.

---

## Tools and Libraries
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scipy, Statsmodels  
- Scikit-Learn  

---

## Steps Performed
1. **Data Preparation** – Loaded, cleaned, and encoded the dataset.  
2. **EDA** – Analyzed placement trends, academic scores, and specialization effects.  
3. **Statistical Tests** – Conducted t-tests and chi-square tests to find significant factors.  
4. **Logistic Regression** – Built a model to predict placement outcomes with 85–90% accuracy.  
5. **Salary Analysis** – Explored salary patterns across degree types and specializations.  

---

## Key Insights
- Academic performance and E-Test scores strongly affect placement success.  
- Work experience nearly doubles placement chances.  
- Mkt&Fin specialization is slightly more demanded by recruiters.  
- Average salary range: 2.5 – 3.0 LPA.
